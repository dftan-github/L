# L CAD

一个用 L 写的迷你交互式绘图工具，用来说明 L 在真实任务上的写法：
场景里图形由**共享的点**构成、命令带橡皮筋预览、按像素距离拾取、
平移缩放，以及即时模式的 GDI 渲染。

参考实现来自父目录 `WAF` 的 `waf.entity.*` / `waf.cmd.entity`
（`CLine` 两端是两个 `CPos` 且中点是自身 `pos()`；`CCircle` 圆心取
`component[0]`、半径由 `component[1]` 到圆心的距离算出）。这里保留
同样的**构图语义**，但改用扁平数组和字节偏移访问，见下文。

## 操作

| 操作 | 效果 |
| --- | --- |
| `L` / `C` / `P` | 进入画线 / 画圆 / 画点命令（提交后自动重复） |
| 左键 | 空闲时拾取图元；命令中放入下一个点 |
| `Esc` | 取消当前命令；空闲时关闭窗口 |
| 滚轮 | 以光标为锚点缩放 |
| 左键拖空白 / 中键拖 | 平移 |
| `Del` | 删除选中图元 |

## 文件

| 文件 | 作用 |
| --- | --- |
| `model.l` | 实体与场景、构图（中点 / 半径）、世界↔屏幕变换 |
| `cmd.l` | 命令状态机：收集点、判满、提交、取消 |
| `render.l` | 网格、图元、HUD 的即时模式绘制 |
| `main.l` | 窗口、事件循环、拾取、缩放平移 |
| `check.l` | 无窗口的逻辑断言（几何 + 命令状态机） |

## 为什么全是 `ptr` 和字节偏移

和 `apps/seditor/tree.l` 记录的是同一组编译器行为：

- 类的 `b = a` 是**按位拷贝**，不是别名。参数写成 `Entity e`
  时函数改的是副本，写入会静默丢失。
- 局部变量 `as ptr` 取的是**栈槽地址**，不是堆对象地址。这个栈槽
  会被后续调用复用，读回来就是垃圾值。

所以实体一律 `l_alloc` 成 `ptr`，字段用 `l_load_*_at` /
`l_store_*_at` 按固定偏移读写。偏移常量集中在 `model.l` 顶部，
和字段列表并排列出，改动时两边一起改。

## 为这个 demo 补的 C 原语

渲染任意斜线和圆需要 GDI 里原本没有的两个操作，加在
`runtime/win32.c` + `stdlib/win32.l`：

- `line(x0, y0, x1, y1, r, g, b)` — `MoveToEx` / `LineTo`，1px 画笔
- `ellipse(x, y, w, h, r, g, b)` — 内接椭圆，只描边不填充

另外 `l_f64_to_i32`（`runtime/io.c`）把世界坐标转成设备像素：语言层
没有隐式收窄，`as i32` 目前也不接受非整数的 f64。

## 构建

```bat
:: 仓库根目录
build_env.bat app apps\cad

:: 只跑逻辑断言（不开窗口）
apps\cad\cad_check.exe
```

`build_env.bat app` 会先重建 `l_runtime` 和 `l`，再编译
`apps\cad\main.l` 与 `apps\cad\check.l`。
